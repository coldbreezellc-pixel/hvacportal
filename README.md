## Structure

```
├── index.html                              ← Landing page
├── pm/
│   └── index.html                          ← PM Work Order form
├── inventories/
│   └── penguin-inventory.html              ← Equipment & Parts Inventory
└── README.md
```

## Setup

1. Create a new repository on GitHub
2. Upload all files maintaining the folder structure above
3. Go to **Settings → Pages → Branch: main → / (root) → Save**
4. Your site will be live in ~1 minute

## Features

### PM Sheet
- PPE acknowledgment gate
- HVAC Safety Checklist (pre-job, electrical, gas/chemical, equipment inspection, post-job)
- Multi-technician support
- Equipment multi-select (Cooling Towers, PCWP, SCWP, CHWP, Liebert Units)
- Dynamic PM checklists from actual PM sheets
- Photo capture from phone camera/gallery
- Auto-generated signature
- PDF generation + email to ecnj.hvaceng@versantmedia.com

### Inventories
- Equipment & parts tracking
